# TradeTime — обновления Android

Публичный канал распространения **подписанных APK** приложения TradeTime.

- **Стабильные версии:** GitHub Releases без отметки Pre-release, теги `vX.Y.Z`.
- **Тестовые версии:** GitHub Releases с отметкой Pre-release, теги `vX.Y.Z-test`.
- APK должен называться `TradeTime-release.apk` и быть подписан постоянным ключом приложения.
- Стабильный релиз публикуется **только после ручного одобрения** владельцем проекта. Успешная CI-сборка не является одобрением.
- Исходный код, секреты, ключи подписи и внутренние файлы здесь не публикуются.

Стабильное приложение проверяет `/releases/latest` и игнорирует prerelease. Тестовое приложение 0.2.7 проверяет конкретный тестовый тег `v0.2.8-test` для изолированной проверки механизма обновления.

[Открыть релизы](https://github.com/NurtazaAIB/TradeTime-Updates/releases)
